## 1. 轉動運動學與等角加速度模型
當一個**剛體**（*Rigid Object*，指在受力時內部各質點相對位置不發生形變的理想物體）繞著固定軸旋轉時，剛體上每一個質點在相同時間內都會轉過相同的角度，因此擁有相同的角速度與角加速度。

> **⚠️ 必考陷阱提醒 (Pitfall Prevention)**：
> 在所有轉動公式中，角度 $\theta$ **必須使用「弧度」（*Radian*, $\text{rad}$）作為單位**，絕對不能直接代入角度（$\text{deg}$）！換算關係：$\pi\text{ rad} = 180^\circ$。

### 📐 重要公式：等角加速度運動學四大公式
當角加速度 $\alpha$ 為定值時，轉動運動學與直線運動學完全對應（將 $x \to \theta$、$v \to \omega$、$a \to \alpha$）：
1. $\omega_f = \omega_i + \alpha t$
2. $\theta_f = \theta_i + \omega_i t + \frac{1}{2}\alpha t^2$
3. $\omega_f^2 = \omega_i^2 + 2\alpha(\theta_f - \theta_i)$
4. $\theta_f = \theta_i + \frac{1}{2}(\omega_i + \omega_f)t$

## 2. 線量與角量的轉換關係
剛體上距離轉軸半徑為 $r$ 的某一點，其切線方向的移動量與轉動角量存在直接比例關係：

> **📐 線量與角量核心轉換公式**
> - **弧長 (Arc Length)**：$s = r\theta$
> - **切線速率 (Tangential Speed)**：$v = r\omega$
> - **切線加速度 (Tangential Acceleration)**：$a_t = r\alpha$
> - **向心（徑向）加速度 (Centripetal / Radial Acceleration)**：$a_c = a_r = \frac{v^2}{r} = r\omega^2$
> - **總線加速度量值 (Total Linear Acceleration)**：$a = \sqrt{a_t^2 + a_r^2} = r\sqrt{\alpha^2 + \omega^4}$

## 3. 力矩與轉動慣量 (必考核心)

### (1) 力矩 (Torque, $\vec{\tau}$)
力矩是造成物體轉動狀態改變的原因，其大小取決於施力大小與**力臂**（*Moment Arm* 或 *Lever Arm*，即轉軸到力作用線的垂直距離）。

> **📐 力矩定義公式**
> $$\tau = rF\sin\phi = Fd$$
> - **方向判斷（右手定則 *Right-Hand Rule*）**：逆時針旋轉傾向定義為**正（$+$）**，順時針定義為**負（$-$）**。
> - **⚠️ 必考觀念**：力矩沒有單一絕對值，它完全取決於你選定的**轉軸（*Axis of Rotation*）**位置。

### (2) 轉動牛頓第二定律與轉動慣量 (Moment of Inertia, $I$)
轉動慣量 $I$ 在轉動中扮演的角色，等同於直線運動中的「質量 $m$」，代表物體抵抗轉動狀態改變的慣性大小。

> **📐 轉動牛頓第二定律與轉動慣量公式**
> $$\sum \tau_{\text{ext}} = I\alpha$$
> - **離散質點系統**：$I = \sum_i m_i r_i^2$
> - **連續剛體積分**：$I = \int r^2 dm = \int \rho r^2 dV$

### (3) 常見均勻剛體轉動慣量表（必背）
- **薄圓環 / 薄圓柱殼**（過中心軸）：$I_{\text{CM}} = MR^2$
- **實心圓柱 / 圓盤**（過中心軸）：$I_{\text{CM}} = \frac{1}{2}MR^2$
- **細長均勻木棒**（過質心垂直軸）：$I_{\text{CM}} = \frac{1}{12}ML^2$
- **細長均勻木棒**（過一端點垂直軸）：$I = \frac{1}{3}ML^2$
- **實心球體**（過球心軸）：$I_{\text{CM}} = \frac{2}{5}MR^2$
- **薄球殼**（過球心軸）：$I_{\text{CM}} = \frac{2}{3}MR^2$

### (4) 平行軸定理 (Parallel-Axis Theorem) —— 🔥 必考公式！
若已知剛體通過**質心**（*Center of Mass*, CM）的轉動慣量 $I_{\text{CM}}$，求平行於該軸且垂直距離為 $D$ 的任意新轉軸之轉動慣量：

> **📐 平行軸定理公式**
> $$I = I_{\text{CM}} + MD^2$$
> - **考點解析**：物體通過質心的轉動慣量永遠是**最小值**，任何偏離質心的平行軸，其轉動慣量必定更大。

## 4. 轉動動能與純滾動運動 (大考壓軸重點)

### (1) 轉動動能與功能定理
- **轉動動能 (Rotational Kinetic Energy)**：$K_R = \frac{1}{2}I\omega^2$
- **轉動功與功率**：$W = \int_{\theta_i}^{\theta_f} \tau d\theta$、瞬時功率 $P = \tau\omega$
- **轉動功能定理**：$W = \frac{1}{2}I\omega_f^2 - \frac{1}{2}I\omega_i^2$

### (2) 剛體的純滾動運動 (Pure Rolling Motion) —— 🔥 綜合題最愛考！
當圓柱或球體在平面上做**無滑動純滾動**（*Rolling Without Slipping*）時，可視為「質心的純移動」加上「繞質心的純轉動」。

> **📐 純滾動核心條件與總動能公式**
> - **無滑動幾何條件**：$v_{\text{CM}} = R\omega$ 且 $a_{\text{CM}} = R\alpha$
> - **地面接觸點瞬時速度**：$v_P = 0$（因此**靜摩擦力不作功**，系統力學能守恆！）
> - **滾動物體總動能**：
>   $$K = K_{\text{rot}} + K_{\text{trans}} = \frac{1}{2}I_{\text{CM}}\omega^2 + \frac{1}{2}Mv_{\text{CM}}^2$$

## 5. 精選例題與必考考點詳解

> **【例題 1】水平釋放的均勻木棒（結合力矩與能量守恆）**
> - **題目敘述**：一根長度為 $L$、質量為 $M$ 的均勻細長木棒，左端以無摩擦樞軸（*Pivot*）固定，從水平位置由靜止釋放。求：(1) 剛釋放瞬間的角加速度 $\alpha$ 與右端點切線加速度 $a_t$；(2) 木棒擺動至最低點（鉛直位置）時的角速度 $\omega$。
> - **🎯 必考考點深度解析**：
>   1. **常見大陷阱**：木棒擺動過程中，重力與木棒的夾角不斷改變，導致**力矩與角加速度並非定值**！因此第 (2) 小題**絕對不能**使用等角加速度公式 $\omega_f^2 = \omega_i^2 + 2\alpha\Delta\theta$，必須改用**力學能守恆定律**！
>   2. **超重現象**：右端點的初始切線加速度高達 $\frac{3}{2}g$（大於重力加速度 $g$），這是物理系普物期中考極愛考的觀念（如高聳煙囪倒塌時會在半空中折斷的原因）。
> - **💡 詳細詳解**：
>   1. **求初始角加速度**：重力 $Mg$ 集中作用於質心（距樞軸 $L/2$ 處），故初始外力矩 $\sum \tau_{\text{ext}} = Mg\left(\frac{L}{2}\right)$。
>      代入 $\sum \tau_{\text{ext}} = I\alpha$（端點轉動慣量 $I = \frac{1}{3}ML^2$）：
>      $$\alpha = \frac{Mg(L/2)}{\frac{1}{3}ML^2} = \frac{3g}{2L}$$
>   2. **求右端點切線加速度**：距離樞軸 $r = L$，故 $a_t = L\alpha = \frac{3}{2}g$。
>   3. **求最低點角速度（能量法）**：取最低點為重力位能零位面，初始時質心高度為 $L/2$：
>      $$\Delta K + \Delta U = 0 \implies \left(\frac{1}{2}I\omega^2 - 0\right) + \left(0 - Mg\frac{L}{2}\right) = 0$$
>      代入 $I = \frac{1}{3}ML^2$ 解得：
>      $$\omega = \sqrt{\frac{MgL}{\frac{1}{3}ML^2}} = \sqrt{\frac{3g}{L}}$$

---

> **【例題 2】有質量的滑輪阿特伍德機 (Atwood Machine with a Massive Pulley)**
> - **題目敘述**：兩物體質量分別為 $m_1$ 與 $m_2$（$m_2 > m_1$），以細繩跨過一個半徑為 $R$、轉動慣量為 $I$ 的滑輪，繩子與滑輪間無滑動。系統由靜止釋放，當 $m_2$ 下降高度 $h$ 時，求兩物體的速率 $v_f$。
> - **🎯 必考考點深度解析**：
>   1. **與高中物理的差異**：高中假設滑輪無質量，兩側繩張力相等；大學普物中滑輪有轉動慣量 $I$，為了使滑輪產生角加速度，**兩側繩張力必然不相等**（$T_2 > T_1$）。
>   2. **最佳解題策略**：直接把「$m_1 + m_2 + \text{滑輪} + \text{地球}$」視為一個孤立系統，用**力學能守恆**列式最快，可完全避開未知的繩張力。
> - **💡 詳細詳解**：
>   1. **列出能量守恆方程式**：系統減少的重力位能全部轉化為「兩物體移動動能」與「滑輪轉動動能」：
>      $$m_2 gh - m_1 gh = \frac{1}{2}m_1 v_f^2 + \frac{1}{2}m_2 v_f^2 + \frac{1}{2}I\omega_f^2$$
>   2. **代入無滑動條件**：因為繩子不滑動，滑輪邊緣切線速率等於物體移動速率，即 $\omega_f = \frac{v_f}{R}$：
>      $$(m_2 - m_1)gh = \frac{1}{2}\left(m_1 + m_2 + \frac{I}{R^2}\right)v_f^2$$
>   3. **解出末速率**：
>      $$v_f = \sqrt{\frac{2(m_2 - m_1)gh}{m_1 + m_2 + I/R^2}}$$

---

> **【例題 3】不同幾何形狀物體沿斜面純滾動比賽**
> - **題目敘述**：將一個均勻實心球（$I_{\text{CM}} = \frac{2}{5}MR^2$）與一個均勻實心圓柱（$I_{\text{CM}} = \frac{1}{2}MR^2$）從高度為 $h$ 的粗糙斜面頂端同時由靜止純滾動釋放，誰會先到達斜面底部？
> - **🎯 必考考點深度解析**：
>   1. **靜摩擦力不做功**：雖然斜面有摩擦力使物體轉動，但接觸點瞬時速度為零，因此靜摩擦力不做功，**力學能依然守恆**！
>   2. **滾動比賽口訣**：到達底部的質心速度為 $v_{\text{CM}} = \sqrt{\frac{2gh}{1 + I_{\text{CM}}/(MR^2)}}$。速度與物體的「質量 $M$」和「半徑 $R$」**完全無關**，只取決於轉動慣量係數 $c = \frac{I_{\text{CM}}}{MR^2}$。**$c$ 越小（質量越集中於轉軸中心），分母越小，滾得越快！**
>   3. **快慢排名（必背）**：無摩擦滑動木塊（$c=0$） $>$ 實心球（$c=2/5$） $>$ 實心圓柱（$c=1/2$） $>$ 薄球殼（$c=2/3$） $>$ 空心圓環（$c=1$）。
> - **💡 詳細詳解**：
>   1. **利用力學能守恆**：重力位能轉為移動動能與轉動動能：
>      $$Mgh = \frac{1}{2}Mv_{\text{CM}}^2 + \frac{1}{2}I_{\text{CM}}\left(\frac{v_{\text{CM}}}{R}\right)^2 = \frac{1}{2}M\left(1 + \frac{I_{\text{CM}}}{MR^2}\right)v_{\text{CM}}^2$$
>   2. **比較兩者速度**：
>      - 實心球（$c = \frac{2}{5}$）：$v_{\text{球}} = \sqrt{\frac{2gh}{1 + 2/5}} = \sqrt{\frac{10}{7}gh} \approx 1.195\sqrt{gh}$
>      - 實心圓柱（$c = \frac{1}{2}$）：$v_{\text{柱}} = \sqrt{\frac{2gh}{1 + 1/2}} = \sqrt{\frac{4}{3}gh} \approx 1.155\sqrt{gh}$
>   3. **結論**：因為 $v_{\text{球}} > v_{\text{柱}}$，且加速度 $a_{\text{CM}} = \frac{g\sin\theta}{1 + c}$ 亦較大，故**實心球先到達底部**。

## 6. 專有名詞對照 (Terminology Notes)
- **Rigid Object**：剛體（受力不發生形變的理想物體）
- **Angular Displacement / Velocity / Acceleration**：角位移 / 角速度 / 角加速度
- **Tangential Velocity / Acceleration**：切線速度 / 切線加速度
- **Centripetal (Radial) Acceleration**：向心（徑向）加速度
- **Torque**：力矩（造成轉動狀態改變的物理量）
- **Moment Arm (Lever Arm)**：力臂（轉軸到力作用線的垂直距離）
- **Moment of Inertia**：轉動慣量（物體抵抗轉動加速度的慣性量度）
- **Parallel-Axis Theorem**：平行軸定理
- **Pure Rolling Motion**：純滾動運動（無滑動滾動）
- **Cycloid**：擺線（滾動輪子邊緣一點在空間中劃出的軌跡）
